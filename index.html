Elvyn

Personal project · In development · Not publicly released

ELVYN — AI-Powered Productivity & Personal Coaching App

A mobile app that combines task planning, Brain Dump capture, daily check-ins and an AI coach. The coach can answer questions using what the user has previously written, and it asks for confirmation before it changes or deletes anything.

  • Backend architecture. Async FastAPI organised by domain, with SQLAlchemy 2.0, Alembic migrations and PostgreSQL on Supabase. Supabase JWTs are verified on every request and every query is scoped to the signed-in user.
  • Retrieval-augmented generation. Brain dumps and check-ins are chunked, embedded with Gemini and stored in pgvector. When a question refers to past entries, the closest chunks are retrieved and passed to the model as context, with their sources shown in the app. The model is not trained on user data.
  • AI suggestions are separate from actions. The model proposes tool calls; creating a task runs directly, while editing or deleting requires explicit user confirmation, and arguments are validated strictly.
  • Background processing. Celery and Redis workers handle reminders, recurring tasks, a transactional outbox for task events, and idempotent indexing with a periodic reconciliation sweep.

React Native (Expo) · TypeScript · Python · FastAPI · PostgreSQL · pgvector · SQLAlchemy · Alembic · Celery · Redis · Gemini

Demo project · Mock payment provider

Savings Vault Ledger

A small fintech ledger service in FastAPI and PostgreSQL. Customers fund locked savings vaults through signed provider webhooks, deposits become ledger entries, and matured vaults are paid out through a guarded transfer call.

  • Webhook signatures (HMAC-SHA512) are verified against the raw request bytes before any JSON parsing.
  • A database UNIQUE constraint on the provider reference prevents double-crediting when two workers race.
  • Payouts claim the vault with a conditional update and commit before the network call, so no lock is held during provider I/O.
  • CI is configured to run ruff, mypy and pytest. The decisions and trade-offs are written up in the repository.
