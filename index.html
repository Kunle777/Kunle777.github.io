About

From architecture to deployment — I own the whole system.

I'm Abdulrazaq Olanipekun — a Computer Science graduate from Crescent University, Abeokuta (Class of 2025) and a software engineer based in Lagos, Nigeria. My focus is system design: taking a product from a blank architecture diagram — data models, API boundaries, infrastructure choices — through to a scalable, deployed system that holds up under real usage.

Python and FastAPI are my core specialization — async SQLAlchemy, Celery/Redis, and SQL-based data design, built with security and auth as first-class concerns rather than an afterthought. I'm equally proficient across the rest of the stack: React, Next.js, React Native, and TypeScript on the frontend and mobile side. My most recent focus has moved into AI engineering — building Retrieval-Augmented Generation (RAG) pipelines and prompt-engineered features that stay grounded in real, structured data instead of generic model output.

I'm not just a web and app developer — I understand a project from the architecture on day one through to the system running securely in production. That includes designing for how a site actually converts a visitor into a client, not just how it looks. I hold a Retrieval-Augmented Generation certification from DeepLearning.AI (Coursera), and run an independent practice, KunleTech, where I take on projects end to end. I'm currently IT Operator at DataGuard NG, and open to freelance and remote software engineering roles.
